# 九大バス時刻表（Android / iPhone 両対応 PWA）

テーマカラーは九大の紫を明るくした `#8a3fb0`。九州大学・昭和自動車・JR各社とは関係のない非公式アプリです。

九州大学 伊都キャンパス周辺の **昭和バス「九州大学線」** の時刻表アプリ。
ブラウザで開いて「ホーム画面に追加」するとアプリとして使え、オフラインでも動きます。

## 機能
- **検索**：「乗る／降りる」カード、⇅入れ替え、「バスを検索」ボタン、次のバスカード。履歴・お気に入りも切り替えて表示
- **停留所検索**：入力で絞り込み、入力履歴、★お気に入り
- **日時指定**：出発／到着、平日・土曜・日祝ダイヤ、時刻を指定
- **検索結果**：縦軸が時刻の時間軸ダイヤ（帯の上端＝発車、下端＝到着）。出発順／早く着く／乗車が短いで並べ替え
- **経路詳細**：乗車時間、途中の停留所と時刻、前の便・次の便、お気に入り、共有
- **時刻表**：時間帯ごとの時刻一覧（経由を色付きの記号で表示）。時刻をタップでその便の詳細へ
- 「伊都キャンパス」を行き先にすると、キャンパス内で最初に着く停留所までの全便を表示
- **のりば表示**：九大学研都市駅の1〜4番のりばなど、乗る・降りるのりばを結果・詳細・時刻表に表示
- **運賃表示**（例：九大学研都市駅→伊都 330円）
- 系統（学園通／快速／横浜西／周船寺／糸島）ごとのオン・オフ切り替え
- 平日 / 土曜 / 日祝 を祝日込みで自動判定、オフライン対応、ダークモード対応

対象系統: 九州大学線（学園通経由・快速・横浜西経由・周船寺経由）/ 九州大学線（糸島・前原駅北口）

## 公開（GitHub Pages）
`main` ブランチに push すると、GitHub Actions（`.github/workflows/pages.yml`）が `app/` フォルダを自動で公開します。

## Android へのインストール
1. 公開URL を Chrome で開く
2. メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」

## 構成
```
app/                 公開するファイル一式（静的サイト）
  index.html, app.js, style.css, sw.js, manifest.webmanifest
  data/timetable.json  時刻表・のりば・運賃データ
  icons/
scripts/
  build_gtfs.py      昭和バスの公式GTFSから app/data/timetable.json を生成（通常はこちら）
  make_icons.py      アイコン生成
```

## 時刻表の更新（ダイヤ改正時）
```bash
python scripts/build_gtfs.py
```
データ元: 佐賀県バスオープンデータ（昭和自動車株式会社 GTFS-JP）http://opendata.sagabus.info/ ・ CC BY 4.0。
年末年始などの特別ダイヤ日もデータから反映します。非公式アプリです。
